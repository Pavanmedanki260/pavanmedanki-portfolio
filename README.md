## ✨ Features

- 🌗 **Dark & Light Theme** — one-click animated toggle
- 🖼️ **Hero Section** — with glowing profile photo, animated background orbs, and key stats
- 🧠 **About Section** — bio, skill tags, and specialty cards
- 💼 **Experience Timeline** — detailed role card with responsibilities
- 🗂️ **Project Cards** — hover effects, tech badges, GitHub & live demo links
- 📬 **Contact Form** — working form with success animation + direct social links
- 📱 **Fully Responsive** — desktop, tablet, and mobile
- ⚡ **Scroll Reveal Animations** — cards animate in as you scroll
- 🔗 **Active Nav Highlight** — highlights current section on scroll

| Technology | Usage |
